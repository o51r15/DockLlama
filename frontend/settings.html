Connect to Ollama

Looking for Ollama…
Just the IP or name is fine; DockLlama adds the port (11434).
Ollama only listens on its own machine unless you change one setting.
  1. Quit Ollama from the system tray (right-click the llama icon → Quit).
  2. Open the Start menu, search for Edit environment variables for your account.
  3. Add a new variable: name OLLAMA_HOST, value 0.0.0.0:11434.
  4. Start Ollama again. If Windows asks about the firewall, allow private networks.
  1. In Terminal, run launchctl setenv OLLAMA_HOST "0.0.0.0:11434"
  2. Quit Ollama from the menu bar and open it again.
  1. Run sudo systemctl edit ollama.service
  2. Add these two lines and save:
    [Service]
    Environment="OLLAMA_HOST=0.0.0.0:11434"
  3. Run sudo systemctl daemon-reload && sudo systemctl restart ollama
  1. Make sure the Ollama container publishes its port: ports: ["11434:11434"] in its compose file.
  2. Then use the IP address of the machine it runs on.
Don't have Ollama yet? Install it from ollama.com/download on a machine with a graphics card if you have one, then come back here.
